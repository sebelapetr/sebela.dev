# .claude/agent-memory-local

Persistent memory of the developer and reviewer agents (`memory: local` in `.claude/agents/`), one folder per agent, created by Claude Code. It lives in the main checkout and is shared by every worktree and every run of the phase loop. Everything here except this file is ignored by git: memory is a local working notebook, not documentation. Findings that stay true belong in `docs/` or an `AGENTS.md`. See `docs/agents.md`.
