# @sebela/memory

The knowledge and retrieval layer: portfolio ingest, embedding indexing and passage search behind ports. Read the root `AGENTS.md` first; this file covers only what is specific to this package.

## What it is

A library called only by the API backend through `@sebela/services` (dependency table in `docs/repository-structure.md`). It may import `@sebela/contracts` and `@sebela/config` only; it never imports `@sebela/db`. `packages/db` implements its persistence ports and `packages/services` composes it with them and the Voyage adapter (`.plan/09-rag/prd.md`).

## Evals

The retrieval evals live in `evals/` and run with Promptfoo (`docs/testing.md`, Memory evals):

| File                           | What it holds                                                                                                                                  |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `datasets/questions.json`      | The fictional EN/CS question set: graded relevance (2/1), canonical paths of judged sources, no-answer questions.                              |
| `datasets/documents/`          | Fictional supplemental documents, including one contradicting an API fact and one with injected instructions.                                  |
| `plan.js`                      | Which cases the system can answer yet (`SEARCHABLE`: the portfolio and the supplemental documents); every other case is pending, never passed. |
| `graders/metrics.js`           | recall@pool, nDCG, precision, MRR, correct/false empty, provenance accuracy, latency percentiles, cost per query.                              |
| `graders/index.js`, `tests.js` | The Promptfoo grader and test generator.                                                                                                       |
| `provider.js`                  | The Promptfoo provider: calls the private search route; never sees the embedding provider's key.                                               |
| `run.js`                       | The runner (`pnpm --filter @sebela/memory eval [--case <id>] [--publish <name>] [--max-cost-usd <n>] [--min-interval-ms <n>]`).                |
| `thresholds.json`              | The gate; not frozen until the deployed variant is chosen.                                                                                     |
| `results/`                     | Published summaries of paid runs.                                                                                                              |

`evals/evals.test.ts` checks the dataset, metrics, plan and options deterministically; it runs with `pnpm test`.

## Module map

The public interface is `src/index.ts`; modules import each other only through their `index.ts`.

| Module                   | Entry                             | Responsibility and hidden decisions                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | Depends on                              | Tests                                 |
| ------------------------ | --------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------- | ------------------------------------- |
| `src/modules/ports`      | `src/modules/ports/index.ts`      | The ports: `Embedder`, `RetrievalStore` (implemented structurally by `packages/db`; the embedding cache, the work queue and stale sources included), `PortfolioSnapshot`, `WorkItem`, `ScheduledWork`, `WorkCounts`; `readRetrievalConfig(env)` (all `RETRIEVAL_*` settings or none, errors naming the setting); `ProviderUnavailableError`, `BudgetExhaustedError`. No SQL, HTTP or wire format.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | `@sebela/contracts`                     | `src/modules/ports/index.test.ts`     |
| `src/modules/ingest`     | `src/modules/ingest/index.ts`     | `portfolioSources(snapshot)`: one source per public record with its canonical site path, sections by field, bounded chunks with text hashes and a version hash per source. Nothing private (the contact email) is indexed.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | `ports`, `@sebela/contracts`            | `src/modules/ingest/index.test.ts`    |
| `src/modules/documents`  | `src/modules/documents/index.ts`  | `prepareDocument({ slug, title, fileName, bytes }, options?)`: the local, provider-free part of supplemental ingest. It checks the slug, the type (Markdown `.md` or text `.txt` by extension, valid UTF-8, no binary signature or control characters), the size, extracted size and processing time (`defaultDocumentLimits`: 1 MiB, 500,000 characters, 10 s), cleans the text (Unicode NFKC, line endings, whitespace, hyphenated line breaks), runs the sensitivity checks (credential and secret formats, private keys, connection strings, e-mail addresses, telephone numbers, national identifiers, bank account numbers) and returns the SHA-256 content hash, findings as kind and line of the original file only, sections by heading and chunks by size with overlap with their parent section and ordinal. Refusals throw `DocumentRejectedError` with a code and an actionable message. Passages get the safe title and the `document:<slug>` identifier, never the file name or an address.                                                                                                                                            | `ingest`                                | `src/modules/documents/index.test.ts` |
| `src/modules/providers`  | `src/modules/providers/index.ts`  | `createVoyageEmbedder(options)` (the Voyage AI wire format, `input_type`, `output_dimension`, timeout per attempt, bounded retries of a 429 after its `Retry-After` or an exponential backoff with jitter, each wait capped; a failure or bad answer is `ProviderUnavailableError` carrying the HTTP status when there was one, never echoing the key) and `createFakeEmbedder()`, a deterministic bag-of-words embedder for tests (optionally failing like an outage, with a given HTTP status). `createQueryCachingEmbedder(embedder, file)` keeps `query` embeddings in a JSON file by model, version, dimension and text (SHA-256 key), embeds only the misses in one call and reports only their tokens, and writes the file atomically; document embeddings are never cached there. The eval runner uses it through `RETRIEVAL_QUERY_CACHE_FILE`.                                                                                                                                                                                                                                                                                               | `ports`                                 | `src/modules/providers/index.test.ts` |
| `src/modules/spend`      | `src/modules/spend/index.ts`      | Every paid provider call: refused with `BudgetExhaustedError` once the calendar month's (UTC) recorded spend reached the ceiling, recorded with its tokens and estimated cost after it answered.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | `ports`                                 | `src/index.test.ts`                   |
| `src/modules/scheduling` | `src/modules/scheduling/index.ts` | `scheduleChanges(store, changes, current)`: turns committed content changes into queued work in one transaction; a deleted record's sources (a project's case study included) leave the index at once, a changed record's sources leave search (stale) until re-indexed; roadmap diary deletes only hide. It also compares the indexed portfolio sources with `current`, the portfolio after the changes: a source missing from it is removed, one whose version differs is marked stale, so records indexed inside others (testimonials, technologies, organizations, a deleted parent's children) leave search too. Changes that map to no one source queue a whole-portfolio item.                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | `ports`, `@sebela/contracts`            | `src/index.test.ts`                   |
| `src/modules/indexing`   | `src/modules/indexing/index.ts`   | `createIndexer(options)`: `reindexPortfolio(snapshot)` brings the index in step with a snapshot, embedding only chunks whose text hash has no cached vector for the model and version, in bounded batches, re-storing stale sources and removing sources no longer present; every returned vector is cached at once, so a retry never embeds or counts it again. `rebuildPortfolio(snapshot)` stores every source again (after a model or version change), each text embedded at most once. `processPending(read, options)` takes up to `workBatchLimit` (500) queued items, reads the snapshot after them, reconciles and drops them; a provider failure counts an attempt on each (failed at `maxWorkAttempts`, 5; `retryFailed` takes failed ones again), the ceiling leaves them untouched. Returns an `IndexReport`/`QueueReport` with tokens, cost, completed and remaining work. `embedDocument(prepared)` embeds an approved supplemental document's chunks within the ceiling (reusing cached vectors by text hash) and returns its source version ready to store with the spend; it is the only document operation that calls the provider. | `ports`, `ingest`, `spend`, `documents` | `src/index.test.ts`                   |
| `src/modules/retrieval`  | `src/modules/retrieval/index.ts`  | `createRetriever(options)`: `search(request)` embeds the query within the ceiling, takes the nearest chunks of the configured model, keeps each source's best chunk at or above the relevance floor and returns contract passages or `no_evidence`; `candidates(questions)` the same pool without the floor for each question, the queries embedded `embeddingBatchSize` per call.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | `ports`, `spend`, `@sebela/contracts`   | `src/index.test.ts`                   |
