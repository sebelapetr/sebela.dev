# Notes from a talk at the Northgate Engineering meetup

A **fictional** document of the demo seed: Alex Novara's own notes for a talk given at a fictional
meetup in Northgate.

## Golden sets

Write forty questions before the first prompt. Grade every answer as answers, related or
irrelevant, and keep the questions in the repository beside the code they test.

## What went wrong

The first golden set had only English questions, so the assistant looked better than it was for
Czech readers. The second set mixes both languages.
