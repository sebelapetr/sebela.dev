# Retrospektiva asistenta pro čtenáře

**Fiktivní** dokument demo dat: krátká retrospektiva projektu asistenta pro čtenáře fiktivního
vydavatelství Lumen Press.

## Proč se spuštění zpozdilo

Testovací skupina se rozšířila až o šest týdnů později. Hodnoticí sada odhalila, že asistent
citoval články ze špatného ročníku archivu, a dokud se to neopravilo, vydání se nepustilo.

## Co si odnášíme

Otázky do hodnoticí sady psát dřív než prompty a měřit vyhledávání odděleně od odpovědí.
