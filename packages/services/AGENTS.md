# @sebela/services

Domain operations of the backend. Read the root `AGENTS.md` first; this file covers only what is specific to this package.

## What it is

A library used by `apps/api` (HTTP routes and the API-key and seed CLIs). It may import `@sebela/db`, `@sebela/contracts`, `@sebela/memory` and `@sebela/config` (dependency table in `docs/repository-structure.md`). It writes no SQL: it asks `@sebela/db` for persistence operations and never sees a table, query builder or connection.

It sends a SHA-256 checksum with every upload, refuses a foreign key before any request, counts a `NoSuchKey` delete as removed and turns SDK failures into plain errors naming the operation and HTTP status, never the password. Its configuration needs `STORAGE_BUNNY_ENDPOINT` (a bare https origin), `STORAGE_BUNNY_REGION`, `STORAGE_BUNNY_ZONE`, `STORAGE_BUNNY_PASSWORD`, an https public base that is not the endpoint host, and `STORAGE_WORKTREE` in `development`; it never falls back to local disk. On Bunny the marker is written without an exclusive create, so two prepares racing for one new folder are not detected.
